Task Manager

A simple task management web app that allows users to add and remove tasks dynamically.

Features

- Add a new task using the input field.
- Mark tasks as complete with a dedicated button.
- Display a live task counter that updates automatically.
- Minimal UI.

Tech Stack

- HTML
- CSS
- JavaScript

How to Run

1. Download the files.
2. Open `index.html` in your browser.

Future Improvements

- Add local storage.
- Add task editing so users can update task text after creation.
- Add a confirmation prompt before deleting a task.
- Add a filter for active/completed tasks.


What I Learned

- Handling user input in JavaScript
- DOM manipulation and event handling
- Structuring simple interactive UI
